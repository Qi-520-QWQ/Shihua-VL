# Strict 口径分层计分分析（2026-11-16 00:35 CST）

本分析检验现行 strict 口径是否过于严苛、是否应分层计分。
数据来源：`data/questions.jsonl`（60 题，required_facts 字段）＋
`ratings/adjudication_carbon.jsonl`（Carbon）＋`ratings/adjudication_2b.jsonl`（2B）。
数字可从上述文件复现。

## 1. 现行口径的严苛程度（实测）

| 指标 | Carbon（Gemini 4 旗舰参照） | InternVL2.5-2B（T4 本地） |
| --- | --- | --- |

| partial 均值（0–2 分，双评者均值） | 1.34/2 | 0.58/2 |

## 2. 核心发现

1. **strict 几乎是「漏一项即零分」的二值开关**：Carbon 55/60 的题至少答对约一半必需事实，
   却只有 4 题全中。strict 测的更多是「是否漏掉任何一项馆方特异事实」，
   而不是「答案整体对不对」。旗舰模型在宽松口径下 91.7% 命中、严格口径下 6.7%，
   两者落差 85 个百分点——口径本身决定了结论的量级。
2. **幻觉率是口径稳健的判别指标**：幻觉判定不依赖 strict 的全中要求，
   Carbon 68.3%、2B 60.0%，两者都远高于预设的退出门槛的 ≤5%。
   即使把命中口径放宽到 partial ≥ 1，幻觉率不变——「缺口确认」的结论不依赖 strict 口径。
3. **两模型的能力差距在任何口径下都存在**：宽松命中 91.7% vs 46.7%，
   partial 均值 1.34 vs 0.58，partial=0 的题 1 vs 18。2B 不是「被严口径冤枉」，
   而是近三分之一的题一条必需事实都没答对。
4. **分维差异在宽松口径下仍然成立**：Carbon 宽松命中名物 18/20、笔墨 18/20、意象 19/20，
   但幻觉名物 19/20、笔墨 13/20、意象 9/20——意象题幻觉显著更低，
   与 docs/decision.md 的三维难度分层结论一致。

## 3. 对预设的退出门槛的影响

预设的退出门槛是「三维各 strict ≥85% 且总幻觉率 ≤5%」。实测说明：

- **幻觉 ≤5% 这一腿在任何口径下都远未达到**（68.3% vs 5%），停止条件不触发——
  「继续」的结论对计分口径选择是稳健的。
- **strict ≥85% 这一腿在现行口径下对旗舰模型也几乎不可达**（6.7% → 85%）。
  若把它当作 26B 微调的达标线，会出现「微调即使把逐事实命中率从 67% 提到 90%，
  strict 仍可能只有三四成」的局面——达标线失去度量意义。
  这不是事后改口径的借口，而是门槛设定时（无数据）未预见到的口径特性，
  须在定稿时如实说明并修正。

## 4. 建议（结论定稿时采纳）

1. **评测包公开时四项指标并报**：strict_hit、partial 均值、宽松命中（partial ≥ 1）、
   hallucination。strict 保留为「全对率」，不再单独作为退出门槛。
2. **退出/达标门槛改为两条**：(a) 幻觉率 ≤5%（口径稳健，现 68.3%）；(b) 逐事实命中率 ≥85%。
   (b) 的精确值须逐事实重评才能得到——现行 partial 是 0/1/2 粗分，
   「约 67% / 约 29%」只是 partial/2 的粗估，**不得当作精确的逐事实命中率引用**。
   若定稿需要 (b) 的精确基线，须对 60 题做逐事实重评（60 题 × 平均 4.3 个事实 ≈ 260 个事实点，
   可走现有双评通道，不新增模型调用以外的成本）。
3. **不重评 v0 的 strict 分数**：v0 的 strict/partial/hallu 三值已锁定并经 Gemini 4 Argon · High 第三方复核，
   改口径只改「如何汇总与设门槛」，不改已裁决的逐题分数——避免为迁就结论改数据。
4. **同一套四指标口径已直接套用于其余各线（见 docs/decision.md）。**

## 5. 限定

- partial 0/1/2 是评者对「命中事实比例」的粗分，不是逐事实打勾；§1 的「粗估逐事实命中率」
  只是 partial/2 的线性换算，误差未量化，仅用于量级比较。
- 本分析只覆盖已裁决的 Carbon 与 2B 两线；其余各线的四指标汇总见 docs/decision.md。
- 事实数量与 strict 的关系样本太小（每档 ≤22 题），未做显著性检验。
